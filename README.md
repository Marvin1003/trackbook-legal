# Trackbook legal pages

Privacy policy, legal notice (Impressum), account deletion and open-source licences for the
Trackbook app, served with GitHub Pages at https://trackbook-app.github.io/legal/.

The source lives in trackbook-app/app under `site/legal` (licences are generated by
`tools/legal/licenses.mjs` there). Change it there and copy it here, so the two stay the same.
